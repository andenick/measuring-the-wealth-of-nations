# Page 100 - Producer and Purchaser Prices in Labor Value Calculations

## Key Concept: Producer vs Purchaser Prices

### Purchaser Price Calculations:
1. **Productive Inputs (M_p)**:
   - M_p = (M_p)_p + (M_p)_t
   - Sum of producer price and trading margin

2. **Total Product (TP*)**:
   - TP* = GO_p + GO_t
   - Sum of productive sector producer prices and trading sector revenues

### Information Limitations in Standard IO Tables:
- Can calculate purchaser prices of aggregate inputs, outputs, final demand
- Cannot calculate purchaser prices of individual commodities
- Trade margins are always combined, lacking individual commodity breakdown

### Labor Value Measures:
- Calculate labor value of various commodity bundles
- Use labor-value/producer-price ratio λ*_j for each commodity
- Apply ratios only to producer price components of commodity flows

### Labor Value Equation:
λ_j = hp_j + Σ_i λ_i · app_{ij}

This represents the sum of:
- Direct productive labor hours (hp_j)
- Indirect labor value through inputs (Σ_i λ_i · app_{ij})

### Skill Adjustment Note:
Sectoral wage-rate differences might correlate with skill differences, but using wages as approximation can cause problems (see Wolff 1975, 1977).
