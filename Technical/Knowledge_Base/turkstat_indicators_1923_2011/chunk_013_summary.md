## Tables Extracted

### chunk_013_table01_broadcasting_employment_2000_2010.csv
**Table 11.43** — Number of broadcasting institutions, employment (continued)  
- Years: 2000–2010  
- Variables: Number of broadcasting institutions, annual average employees (ücretle çalışanlar), annual average persons engaged  
- Breakdowns: by broadcasting type (Radio, Radio-TV, Television) and geographic scope (A=All, B=National, C=Regional, D=Local, E=Satellite/cable from 2009)  
- Total all-type employment (A): 21,038 (2000) → 15,510 (2010), with peak of ~21k in 2000 declining to ~13k mid-decade then recovering to ~15.5k by 2010  
- Note: Satellite/cable institutions included from 2009 reference year

### chunk_013_table02_broadcasting_compensation_va_1995_1997.csv
**Table 11.44** — Some basic indicators by type of broadcasting  
- Years: 1995–1997 (only three years visible in this chunk)  
- Variables (Million TL, current): Gross payments to employees, Input, Output, Value added  
- NACE Rev.2 code 60: Programming and broadcasting activities  
- Total all-broadcasting gross payments to employees: 5,423 Mn TL (1995) → 10,232 Mn TL (1996) → 29,948 Mn TL (1997) — rapid nominal growth during high-inflation period  
- Total value added: 23,424 Mn TL (1995) → 37,761 Mn TL (1996) → 118,832 Mn TL (1997)
