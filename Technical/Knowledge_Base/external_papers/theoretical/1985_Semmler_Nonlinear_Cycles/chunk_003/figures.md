## Figure 1: Stable Limit Cycle in (u, g) Phase Space

**Location:** Page 171

**Type:** Phase diagram / trajectory plot

**Description:**
This figure displays a phase diagram showing the relationship between the inverse employment rate (u) on the horizontal axis and the accumulation rate (g) on the vertical axis. The diagram illustrates a stable limit cycle generated by the nonlinear growth cycle model.

**Key Features:**
- Axes: Horizontal axis represents u (inverse employment rate), vertical axis represents g (accumulation rate)
- Shows trajectories from various initial conditions converging to a closed orbit (limit cycle)
- The limit cycle represents a self-sustained oscillation independent of initial conditions
- The equilibrium point (u*, g*) appears at the center of the limit cycle
- Multiple trajectories spiraling inward toward the limit cycle demonstrate stability

**Parameters Used:**
- σ = 0.4 (maximum output-capital ratio)
- w₀ = 0.05 (minimum wage parameter)
- w₁ = 0.15 (wage sensitivity parameter)
- γ = 2 (wage function nonlinearity)
- gₘᵢₙ = -0.1 (minimum accumulation rate)
- gₘₐₓ = 0.3 (maximum accumulation rate)
- r₀ = 0.2 (reference profit rate)
- δ = 0.05 (accumulation function smoothness)
- n = 0.02 (labor supply growth rate)

**Cycle Characteristics:**
- Period: approximately 10 time periods
- Inverse employment rate (u) oscillates between approximately 1.2 and 2.0
- Corresponding employment rate (v = 1/u) oscillates between 50% and 83%
- Accumulation rate oscillates between approximately -5% and 20%

**Context:** This figure demonstrates that with appropriate nonlinear specifications, the model generates an endogenous business cycle (limit cycle) rather than converging to a steady state or diverging.

**Type:** Time series plot

**Description:**
This figure displays a time series showing the evolution of the inverse employment rate u(t) over 200 time periods. The series exhibits chaotic dynamics with irregular, aperiodic oscillations.

**Key Features:**
- Horizontal axis: time (t), ranging from 0 to 200 periods
- Vertical axis: u(t) (inverse employment rate)
- Irregular oscillations with no repeating pattern
- Bounded behavior (oscillations remain within finite range)
- Aperiodic fluctuations characteristic of deterministic chaos
- Sensitive dependence on initial conditions (not shown but implied)

**Parameters Used:**
- σ = 0.4
- w₀ = 0.05
- w₁ = 0.15
- γ = 4 (further increased nonlinearity)
- gₘᵢₙ = -0.1
- gₘₐₓ = 0.3
- r₀ = 0.2
- δ = 0.02 (further decreased smoothness)
- n = 0.02

**Characteristics of Chaos:**
1. Sensitive dependence on initial conditions - small changes in starting values lead to dramatically different trajectories
2. Aperiodic behavior - no repeating pattern over time
3. Bounded oscillations - the system doesn't diverge to infinity

**Context:** This demonstrates that with sufficiently strong nonlinearities, the discrete time growth cycle model can generate chaotic dynamics, providing a potential explanation for irregular business cycle patterns without requiring exogenous shocks.

## Figure 4: Bifurcation Diagram

**Location:** Page 173

**Type:** Bifurcation diagram

**Description:**
This figure shows a bifurcation diagram illustrating how the long-run behavior of the system changes as the parameter δ (smoothness of accumulation function) varies from 0.01 to 0.1, while holding all other parameters constant.

**Key Features:**
- Horizontal axis: δ (smoothness parameter), ranging from 0.01 to 0.1
- Vertical axis: long-run values of u (after transients die out)
- Shows period-doubling route to chaos as δ decreases
- Multiple solution branches visible
- Transition from simple periodic behavior (single point or few points for each δ) to complex chaotic behavior (dense cloud of points)

**Observed Pattern:**
- At higher values of δ (right side): stable limit cycle appears as discrete points
- As δ decreases: period-doubling bifurcations occur
  - First: period-2 cycle (two distinct points)
  - Then: period-4 cycle (four distinct points)
  - Then: period-8 cycle (eight distinct points)
  - Continuing period-doubling cascade
- At low values of δ (left side): chaotic regime with dense scatter of points

**Context:** This bifurcation diagram provides a systematic view of how the model transitions from simple periodic behavior to chaos through a period-doubling cascade. This is a well-known route to chaos in nonlinear dynamical systems, demonstrating that the economic model exhibits the same mathematical structure as other chaotic systems.

## Figure 5: Comparison of Continuous vs. Discrete Time Dynamics

**Location:** Page 174

**Type:** Comparative phase diagram

**Description:**
This figure compares the phase diagrams (trajectories in (u, g) space) for the continuous time version of the model versus the discrete time version with different time steps.

**Key Features:**
- Multiple trajectories shown with different line styles:
  - Solid line: continuous time model solution
  - Dashed lines: discrete time model with various time step sizes
- All trajectories show limit cycles
- Demonstrates how discrete time introduces additional complexity

**Comparison Details:**
- Continuous time model (solid line): smooth limit cycle
- Discrete time with small time step (fine dashed): closely approximates continuous time
- Discrete time with moderate time step (medium dashed): shows some overshooting
- Discrete time with large time step (coarse dashed): exhibits more pronounced overshooting and different cycle shape

**Key Insight:**
Discrete time formulation can introduce dynamics not present in continuous time:
1. **Overshooting and undershooting** - the system can jump past equilibrium values
2. **Period doubling** - cycles can have longer periods in discrete time
3. **Chaos** - discrete time can generate chaos even when continuous time would have simple limit cycle

**Context:** This comparison demonstrates that the choice between continuous and discrete time is not merely a technical detail but can fundamentally affect the dynamic behavior of the model. Discrete time may be more realistic for economic applications where decisions and adjustments occur at discrete intervals (quarterly, annually, etc.), and the additional complexity it introduces may help explain irregular patterns in real business cycles.
