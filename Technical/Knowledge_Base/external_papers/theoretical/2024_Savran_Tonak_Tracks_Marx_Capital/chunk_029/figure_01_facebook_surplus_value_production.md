# Figure 1: Facebook and Surplus-Value Production

**Source:** Chapter 12, Page 261

**Type:** Flow diagram showing two-stage production process

## Description

A complex flow diagram illustrating Facebook's production process and surplus-value generation across two stages.

### Stage I (Facebook)

**Initial Elements:**
- **Facebook:** Capitalist
- **M (money):** Initial investment

**Production Process:**
- **C (commodities):** Means of Production (buildings, servers, etc.) + Labor Power (engineers, repairmen, janitors, etc.)
- **P (production):** Combines constant capital (non-productive equipment and environment) and variable capital

**Output:**
- Creates **C'modified (social interaction environment):** A new production of raw materials/modified commodity for Facebook
- **Surplus value production:** Generated through this initial stage
- **User:** Petty commodity producer
- Enables Facebook to create **a modified commodity, targetable audience** to be sold to advertisers

**Relationship:**
- Access to Facebook established
- Better targeting occurs

### Stage II

**Key Elements:**
- **C'modified (social interaction environment):** Input from Stage I
- **C'modified (targetable audiences):** Output product

**Process:**
- User content becomes raw material
- A new production of **P (production):** Occurs
- Creates modified commodity, **targetable AUDIENCE** to be sold to advertisers
- Enabling Facebook to create a modified commodity
- Surplus value production continues

**Flow Characteristics:**
- Red diagonal line labeled "Better targeting" connects the stages
- Multiple feedback loops showing:
  - "no surplus value production" (user side)
  - "surplus value production" (Facebook side)
  - "access to Facebook" enabling the cycle

## Interpretation

The diagram demonstrates Marx's theory of surplus-value applied to digital platforms, showing:

1. Facebook produces a social interaction environment as a commodity
2. Users contribute content as "petty commodity producers" without monetary exchange
3. User content becomes means of production (constant capital) for Facebook
4. Facebook packages users and content as "targetable audiences"
5. These audiences are sold to advertisers, generating surplus-value
6. The process occurs in two stages: initial platform creation, then audience commodification

## Key Concepts Illustrated

- **Constant Capital (C):** Buildings, servers, equipment
- **Variable Capital (V):** Labor power of employees
- **Surplus Value (S):** Generated from productive labor
- **Modified Commodity:** User content transforming the platform
- **End Product:** Targetable audience sold to advertisers
- **Petty Commodity Producer:** User generating content without wage payment
- **Means of Production:** User content serving as raw material for Stage II
