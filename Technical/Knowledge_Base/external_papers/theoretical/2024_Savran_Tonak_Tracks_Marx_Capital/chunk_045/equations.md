3. **Value of Labour-Power and Surplus-Value (Marx)**
   - Value of labour-power (given) < Total new value created
   - Surplus-value = Total new value created - Value of labour-power
   - The relationship is one of necessary inequality (not mutual independence)

4. **Working Day Composition (Marx)**
   - Working day = Necessary labour time + Surplus labour time
   - Necessary labour time = time required to reproduce value of labour-power
   - Surplus labour time = source of surplus-value
