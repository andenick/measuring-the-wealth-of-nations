# Argument Structure - Chunk 014
## Visual Map of Theoretical Development

```
CHAPTER 5: PRODUCTIVE AND UNPRODUCTIVE LABOUR
│
├─[Pages 105-107] SERVICES AND PRODUCTIVE LABOUR
│  │
│  ├─ Marx vs Smith's Second Definition
│  │  ├─ Marx: Use-value type irrelevant to productivity
│  │  ├─ Marx: Services can be productive (schoolmaster example)
│  │  └─ Marx: Productive = produces surplus-value for capital
│  │
│  ├─ Smith's Error: Conflation of Two "Services"
│  │  ├─ ERROR 1: Social relationship (menial servant = revenue exchange)
│  │  ├─ ERROR 2: Nature of product (intangible/immaterial)
│  │  └─ CONFLATION: Treated as necessarily connected
│  │
│  ├─ Poulantzas Repeats Error (1975)
│  │  ├─ Claims all service labour is unproductive
│  │  ├─ Goes further: Excludes service workers from working class
│  │  └─ Translation error obscured argument (fn 24)
│  │
│  └─ Correct Definition of Services
│     ├─ NOT: Immateriality or intangibility
│     ├─ NOT: Buying labour vs labour-power
│     ├─ CORRECT: Simultaneity of production and consumption
│     ├─ Product not separable from act of producing
│     ├─ Services involve material inputs (scissors, chairs, ingredients)
│     ├─ Services often have material outputs (meal, haircut, cleaned coat)
│     └─ CONCLUSION: Service = commodity when capitalistically organized
│
├─[Pages 108-110] SECTION 5: STATE EMPLOYEES
│  │
│  ├─ Three Categories of State Activities
│  │
│  ├─[1] REPRODUCTION OF SOCIAL ORDER
│  │  ├─ Examples: Military, police, courts, prisons, administration
│  │  ├─ Status: UNPRODUCTIVE BY DEFINITION
│  │  ├─ Reason: Not productive in general (don't transform nature)
│  │  └─ Wages = faux frais of capitalism
│  │
│  ├─[2] STATE ENTERPRISES (Production)
│  │  ├─ Examples: State-owned factories, utilities, companies
│  │  ├─ Status: PRODUCTIVE (identical to private capital)
│  │  ├─ Reason: Organize production to extract surplus-value
│  │  └─ Political differences (prices, losses) don't change capitalist nature
│  │
│  └─[3] SOCIAL SERVICES (Welfare State)
│     ├─ Examples: Public education, healthcare, housing
│     ├─ Status: CONTINGENT (depends on organization)
│     │
│     ├─ UNPRODUCTIVE WHEN:
│     │  ├─ Not sold as commodities
│     │  ├─ Provided free to recipients
│     │  └─ National health/education systems
│     │
│     ├─ PRODUCTIVE WHEN:
│     │  ├─ Sold as commodities
│     │  ├─ Fees approach market prices
│     │  └─ Privatized (become capitalist enterprises)
│     │
│     └─ IMPLICATION: Privatization = shift unproductive → productive
│
└─[Pages 111-114] SECTION 6: SOME MISCONCEPTIONS
   │
   ├─ OBJECTION 1: "Circulation workers contribute to use-values"
   │  │  (e.g., salespeople displaying goods)
   │  │
   │  └─ RESPONSE:
   │     ├─ Distinguish production-related activities from pure circulation
   │     ├─ Displaying goods (necessary link to consumer) = productive
   │     ├─ Cashier transactions (pure change of form) = unproductive
   │     └─ Conceptually clear despite empirical measurement challenges
   │
   ├─ OBJECTION 2: "Circulation necessary in all societies → productive"
   │  │
   │  └─ RESPONSE:
   │     ├─ CONFUSES: Circulation of use-values vs circulation of commodities
   │     ├─ Use-value flows are universal (necessary in all societies)
   │     ├─ Commodity/money/capital circulation is historically specific
   │     ├─ Alternative forms possible (central planning, rationing)
   │     └─ Pure circulation (C-M exchange) can be eliminated
   │
   ├─ OBJECTION 3: "Calling circulation unproductive is normative/moralistic"
   │  │
   │  └─ RESPONSE:
   │     ├─ REVERSES CAUSALITY: Not "irrational → unproductive"
   │     ├─ But "unproductive → irrational"
   │     ├─ GROUND: Society increases wealth only through transforming nature
   │     ├─ Circulation merely redistributes existing product
   │     ├─ PUPL = logical extension of production/circulation distinction
   │     └─ No more normative than production/circulation distinction itself
   │
   └─ OBJECTION 4: "Marx contradicts himself on use-value types"
      │  (Claims type irrelevant, but excludes circulation)
      │
      └─ RESPONSE: DOUBLE DETERMINATION CONCEPT
         │
         ├─ PRODUCTIVE LABOUR IN GENERAL (Condition 1)
         │  ├─ Transforms nature to satisfy human needs
         │  ├─ Transhistorical (applies to all modes of production)
         │  └─ NECESSARY but INSUFFICIENT for productive labour under capitalism
         │
         ├─ PRODUCTIVE LABOUR FOR CAPITAL (Condition 2)
         │  ├─ Employed by capital (not revenue)
         │  └─ Produces surplus-value
         │
         ├─ LOGICAL RELATIONSHIP:
         │  │
         │  │  [Productive Labour in General] ⊃ [Productive Labour for Capital]
         │  │         (Superset)                      (Subset)
         │  │
         │  └─ Productive under capitalism = INTERSECTION of both conditions
         │
         ├─ APPLICATION TO CIRCULATION:
         │  ├─ Fails Condition 1 (not productive in general)
         │  ├─ Therefore automatically fails overall test
         │  └─ Use-value type (steel vs haircut) irrelevant WITHIN Condition 1
         │
         └─ NO CONTRADICTION:
            ├─ Steel vs haircuts: Both transform nature → type irrelevant
            └─ Circulation: Doesn't transform nature → excluded by first criterion
```

│  │

│  │

│     │

│        │    (Wages paid from capital, not revenue?)
│        │
│        ├─ NO → UNPRODUCTIVE CONTINGENTLY
│        │  │     Examples: Domestic servants, free public services
│        │  └─────── END: Unproductive
│        │
│        └─ YES → Passes second test, proceed to Q3
│           │

│              │  └─────── END: Unproductive
│              │
│              └─ YES → ✓ ✓ ✓ PRODUCTIVE LABOUR
│                        Examples: Factory workers, service workers in
│                        capitalist firms, state enterprise workers

## Conceptual Hierarchy

```
PRODUCTIVE LABOUR IN GENERAL
│
├─ Definition: Transforms nature to satisfy human needs
├─ Scope: Transhistorical (all modes of production)
├─ Examples: Agriculture, manufacturing, construction, transport, services
│
└─ Contains subset:
   │
   PRODUCTIVE LABOUR UNDER CAPITALISM
   │
   ├─ Additional requirement: Employed by capital
   ├─ Scope: Specific to capitalism
   ├─ Function: Produces surplus-value
   │
   └─ Excludes:
      │
      ├─[1] Labour not productive in general
      │     ├─ Circulation activities
      │     ├─ Social order reproduction
      │     └─ Pure administration
      │
      └─[2] Productive in general but not employed by capital
            ├─ Domestic servants (revenue exchange)
            ├─ Free public services
            └─ Self-employed artisans (simple commodity production)
```

## Evolution of Concepts: Smith → Marx → Critics → Savran & Tonak

```
ADAM SMITH (Wealth of Nations)
│
├─ Definition 1 (Correct): Productive = employed by capital
├─ Definition 2 (Flawed): Productive = material/durable product
│  └─ CONFLATION: Material product + Revenue exchange → Services unproductive
│
↓
│
KARL MARX (Capital, Theories of Surplus Value)
│
├─ CRITIQUE: Smith conflates two dimensions
│  ├─ Social relationship (capital vs revenue)
│  └─ Nature of product (material vs immaterial)
│
├─ CORRECTION: Productive = produces surplus-value for capital
│  ├─ Independent of use-value type
│  ├─ Services can be productive
│  └─ School example: Teacher enriching owner
│
└─ FOUNDATION: "Productive labour in general" concept
   └─ Transforms nature to satisfy needs
│
↓
│
NICOS POULANTZAS (1975)
│
├─ ERROR: Repeats Smith's conflation
├─ Claims all service labour unproductive
└─ Excludes service workers from working class
│
↓
│
OTHER CRITICS (Gough, Harrison, Hunt, de Vroey, Laibman)
│
├─ Objection 1: Circulation contributes to use-values
├─ Objection 2: Circulation necessary in all societies
├─ Objection 3: PUPL distinction is normative
└─ Objection 4: Marx contradicts himself
│
↓
│
SAVRAN & TONAK (This Work - 2024)
│
├─ DEFENSE: Systematic response to all objections
│
├─ CLARIFICATIONS:
│  ├─ Services = simultaneity of production/consumption
│  ├─ Productive in general ⊃ Productive for capital
│  ├─ Circulation of use-values ≠ Circulation of commodities
│  └─ PUPL = objective, not normative
│
├─ EXTENSIONS:
│  ├─ State employee taxonomy (3 categories)
│  ├─ Business services classification
│  └─ Privatization implications
│
└─ PURPOSE: Ground empirical classification for national accounts
```

## Key Distinctions Summary

```
CRITICAL DISTINCTIONS TO MAINTAIN
│
├─ Production ≠ Circulation
│  ├─ Production: Transforms nature, creates use-values
│  └─ Circulation: Changes form (C-M-C), redistributes value
│
├─ Circulation of Use-Values ≠ Circulation of Commodities
│  ├─ Use-values: Material flows (universal)
│  └─ Commodities: Value-form changes (historically specific)
│
├─ Productive in General ≠ Productive for Capital
│  ├─ In general: Transforms nature (transhistorical)
│  └─ For capital: Produces surplus-value (capitalist mode)
│
├─ Material Product ≠ Productive Labour
│  ├─ Material: Physical durability (irrelevant)
│  └─ Productive: Surplus-value production (determinant)
│
├─ Social Relationship ≠ Nature of Product
│  ├─ Relationship: Capital vs revenue (determines productivity)
│  └─ Product: Material vs immaterial (irrelevant)
│
└─ Use-Value Type ≠ Productivity
   ├─ Type: Steel vs haircut (irrelevant within productive in general)
   └─ Productivity: Does it transform nature? (determinant)
```

## Logical Structure of Response to Objection 4

```
OBJECTION: "Marx says use-value type irrelevant, but excludes circulation"

RESPONSE STRUCTURE:
│
├─ PREMISE 1: Productive labour under capitalism has two conditions
│  ├─[A] Productive in general (transforms nature)
│  └─[B] Employed by capital (produces surplus-value)
│
├─ PREMISE 2: Condition A is necessary but insufficient
│  └─ ∴ Productive for capital ⊂ Productive in general
│
├─ PREMISE 3: Within set A, use-value type is irrelevant
│  ├─ Steel production transforms nature → ∈ A
│  ├─ Haircut service transforms nature → ∈ A
│  └─ Steel ≠ Haircut, but BOTH ∈ A → Type irrelevant
│
├─ PREMISE 4: Circulation does not transform nature
│  └─ ∴ Circulation ∉ A
│
├─ CONCLUSION 1: Circulation fails first condition
│  └─ ∴ Automatically excluded from productive labour
│
├─ CONCLUSION 2: Exclusion based on failing Condition A
│  └─ ∴ NOT based on use-value type
│
└─ FINAL: No contradiction
   ├─ Type irrelevant WITHIN set A (productive in general)
   └─ Circulation excluded because NOT IN set A
```
