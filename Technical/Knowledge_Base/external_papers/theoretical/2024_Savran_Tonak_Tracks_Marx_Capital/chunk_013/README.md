### Four-Criteria Framework

Labour is productive for capital ONLY if ALL four conditions met:
1. **Commodity production** (not use-value production)
2. **Wage-labour** (sale of labour-power)
3. **Exchange against capital** (not revenue)
4. **Production sphere** (not circulation)
