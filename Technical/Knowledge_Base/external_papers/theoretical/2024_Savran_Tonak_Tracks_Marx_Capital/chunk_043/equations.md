## Conceptual Mathematical Frameworks Discussed

### Chapter 17: The Negation of "Negative Values"

1. **Method of Simultaneous Equations (Steedman)**
   - Description: System of equations where the same identical value is attributed to commodities produced by different methods
   - Issue raised: When two production equations are included but the same value is assigned, the number of equations exceeds unknowns, making the system indeterminate
   - Context: Joint production scenarios

2. **Marx's Value Calculation Method**
   - Description: Value calculated through addition of:
     - Constant capital (used portion)
     - Variable capital
     - Surplus-value
   - Context: Transfer of value from means of production to final product

3. **Fixed Capital Depreciation**
   - Marx's conception: Linear depreciation with respect to use-value (not time)
   - Each unit produced during the instrument's lifespan receives the same amount of value
   - Individual values vary above or below social value depending on efficiency in different periods

### Chapter 18: On the Theoretical Consistency of Sraffa's Economics

4. **Sraffa's System of Equations**
   - Formal system based on technological requirements of production
   - Called "conditions of production" or "the system"
   - Number of unknowns exceeds number of equations by one
   - Unknowns: prices, rate of profit, wage
   - Requires one "independent variable" to be determined exogenously

5. **Technological Matrix**
   - Changes with every change in wage (if wage specified as aggregate of commodities)
   - Each technological matrix corresponds to a unique standard commodity
