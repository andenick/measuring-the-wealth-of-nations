# Figure 5: State Intervention in Profits

**Location**: Page 206 (book page 206)

**Type**: Flow diagram showing state intervention in capital income

**Description**:
This figure shows how state taxation and expenditures/transfers convert nominal surplus-value into effective surplus-value for both unproductive and productive sectors.

**Diagram Structure**:

```
s ──┬─→ s_upπ + (public expenditure_upπ - tax_upπ) ────→ s_upπ eff
    │
    └─→ s_p + (public expenditure_p - tax_p) ────→ s_p eff
```

**Symbol Definitions**:
- s = Total surplus-value
- s_upπ = Nominal profits of unproductive companies
- s_upπ eff = Effective (post-tax and transfer) profits of unproductive companies
- s_p = Nominal surplus-value of productive companies
- s_p eff = Effective (post-tax and transfer) surplus-value of productive companies
- tax_upπ = Taxes on unproductive sector profits
- tax_p = Taxes on productive sector profits
- public expenditure_upπ = State expenditures/transfers to unproductive sector
- public expenditure_p = State expenditures/transfers to productive sector

**Key Transformation**:
Nominal surplus-value → Effective surplus-value
- For unproductive: s_upπ → s_upπ eff = s_upπ + public expenditure_upπ - tax_upπ
- For productive: s_p → s_p eff = s_p + public expenditure_p - tax_p

**Caption**: "State intervention in profits"

**Analytical Note**:
The authors note that such activities of the state oriented towards capital have been excluded from the empirical domain of their study, which focuses on state intervention in labour income.
