# Figure 3: Capitalist Production and the State—The "Mixed Economy"

**Location**: Page 204 (book page 204)

**Type**: Circuit diagram with taxation annotation

**Description**:
This figure expands on Figure 2 by showing how the state's taxation activities target different components of the gross product.

**Diagram Elements**:

**Private Sector**:
```
M_P ... C_P ──→ LP_P
            └──→ MP_P  ... P_P ... C'_P ... M'_P
```

**State Sector**:
```
M_S ... C_S ──→ LP_S
            └──→ MP_S  ... P_S ... C'_S ... M'_S
```

**Combined Output with Taxation**:
```
                                    ┌─ c   │ untaxed
M'_P + M'_S = M' ──→               ├─ v   │ taxed
                                    └─ s   │ taxed
```

**Symbol Definitions**:
- c = Constant capital (means of production consumed)
- v = Variable capital (wages/labour power)
- s = Surplus-value
- M' = Total money value of production

**Key Relationships**:
- Constant capital (c) remains untaxed (fund for replenishing means of production)
- Variable capital (v) is subject to taxation
- Surplus-value (s) is subject to taxation

**Caption**: "Capitalist production and the state—the 'mixed economy'"

**Theoretical Significance**:
This diagram introduces the state's taxation function, showing that the monetary magnitudes targeted by taxation and public spending are variable capital (v) and surplus-value (s), while constant capital (c) is invested to replenish consumed means of production and remains untaxed.
