# Figure 6: State Intervention in Labour Income

**Location**: Page 206 (book page 206)

**Type**: Flow diagram showing state intervention in labour income

**Description**:
This figure illustrates how state taxation and expenditures/transfers convert nominal wages into effective wages for both unproductive workers and productive workers, introducing the concept of Net Social Wage (NSW).

**Diagram Structure**:

```
W_up ──→ w_up + public expenditure_upw - tax_upw ──→ w_up eff
                 └──────────────┬──────────────┘
                              B_upw      T_up
                 └──────────────────────┘
                     NSW_upw = B_upw - T_upw


v ──→ v + public expenditure_v - tax_v ──→ v_eff
           └──────────────┬──────────────┘
                        B_v      T_v
           └──────────────────────┘
               NSW_v = B_v - T_v
```

**Symbol Definitions**:

**For Unproductive Workers:**
- W_up = Nominal wage of unproductive workers
- w_up eff = Effective (post-tax and transfer) wage of unproductive workers
- B_upw = Benefits/expenditures to unproductive workers
- T_up = Taxes on unproductive workers
- NSW_upw = Net Social Wage for unproductive workers (B_upw - T_up)

**For Productive Workers:**
- v = Nominal variable capital (wages of productive workers)
- v_eff = Effective (post-tax and transfer) variable capital
- B_v = Benefits/expenditures to productive workers
- T_v = Taxes on productive workers
- NSW_v = Net Social Wage for productive workers (B_v - T_v)

**Key Formula**:
**NSW = B - T**

Where:
- NSW = Net Social Wage
- B = Public expenditures/transfers benefiting working population
- T = Taxes paid by working class

**Caption**: "State intervention in labour income"

**Theoretical Significance**:
This diagram is central to the chapter's analysis. It shows that:
1. Nominal wages are converted to effective wages through state intervention
2. The Net Social Wage (NSW) can be positive or negative
3. When NSW is negative, effective variable capital < nominal variable capital, which increases the rate of surplus-value
4. The net effect depends on both taxation AND expenditures/transfers together

**Impact on Rate of Surplus-Value**:
- If NSW < 0: v_eff < v, therefore s/v_eff > s/v (rate increases)
- If NSW > 0: v_eff > v, therefore s/v_eff < s/v (rate decreases)
