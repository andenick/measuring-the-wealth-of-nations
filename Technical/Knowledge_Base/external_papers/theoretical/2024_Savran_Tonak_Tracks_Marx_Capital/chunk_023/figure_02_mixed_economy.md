# Figure 2: Capitalist Production—The "Mixed Economy"

**Location**: Page 204 (book page 204)

**Type**: Circuit diagram

**Description**:
This figure illustrates the circuit of capital in a mixed economy, showing both private and state sector production.

**Diagram Elements**:

**Private Sector**:
```
M_P ... C_P ──→ LP_P
            └──→ MP_P  ... P_P ... C'_P ... M'_P
```

**State Sector**:
```
M_S ... C_S ──→ LP_S
            └──→ MP_S  ... P_S ... C'_S ... M'_S
```

**Combined Output**:
```
M'_P + M'_S = M' ──→ M' - (M_P + M_S) = s
```

**Symbol Definitions**:
- M = Money capital invested
- LP = Labour Power
- MP = Means of Production
- C = Commodities/Capital
- P = Production process
- C' = New commodities (commodity capital)
- M' = Money value of newly produced commodities
- s = Surplus-value (money form)
- Subscript P = Private sector
- Subscript S = State sector

**Key Relationship**:
The gross product of the "mixed economy" = M_P + M_S

Surplus-value (s) = M' - (M_P + M_S)

**Caption**: "Capitalist production—the 'mixed economy'"

**Theoretical Significance**:
Demonstrates that state economic enterprises are treated on the same footing as private sector production, with both contributing to total surplus-value generation.
