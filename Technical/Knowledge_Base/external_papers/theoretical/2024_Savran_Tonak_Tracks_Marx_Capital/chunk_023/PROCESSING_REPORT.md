1. **Methodological Critique**:
   - Previous social wage literature (Gough, Bowles & Gintis) flawed
   - Cannot analyze expenditures alone; must include taxation
   - NSW = B - T is correct formulation

2. **Political Economy Claim**:
   - Social wage NOT inherently pro-labour
   - When NSW < 0, state policy increases exploitation (raises s/v)
   - Class character of fiscal policy is empirical question

3. **Circuit of Capital Extension**:
   - State can be integrated into circuit analysis
   - Distinguishes productive/unproductive sectors
   - Shows conversion: nominal → effective magnitudes

4. **Rate of Surplus-Value Impact**:
   - NSW directly affects variable capital
   - When NSW negative: v_eff < v, so s/v_eff > s/v
   - State intervention can intensify exploitation

### Implications

- Challenges left assumptions about welfare state
- Provides framework for empirical class analysis of fiscal policy
- Shows neoliberal austerity may involve negative NSW
- Links macro aggregates to class relations
