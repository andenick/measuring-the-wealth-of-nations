# Table 1: The Wolfstetter Condition for Negative Values

## Table Content

|---|---|---|---|---|---|---|---|
| | Commodity 1 | Commodity 2 | Labor | Commodity 1 | Commodity 2 | Commodity 1 | Commodity 2 |

## Table Context

This table illustrates the Wolfstetter condition for the appearance of negative values in joint production scenarios. The table shows two different processes that produce the same two commodities, demonstrating an absolute difference in productivity between the processes.

## Key Features

- **Process 1** produces a net product of 1 unit of each commodity (Commodity 1 and Commodity 2)
- **Process 2** produces a net product of 3 units of Commodity 1 and 2 units of Commodity 2
- Both processes use 1 unit of labor
- The processes have different input requirements (Process 1 uses 5 units of Commodity 1, Process 2 uses 10 units of Commodity 2)
- This absolute difference in productivity is a necessary condition for negative values to arise according to Wolfstetter (1976)

## Theoretical Significance

The table demonstrates that negative values can only arise under conditions where there is an absolute difference in productivity between two processes producing the same commodities jointly. This is central to Savran's critique of Steedman's argument about negative values in Marx's value theory.
