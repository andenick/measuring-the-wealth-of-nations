# Chopped Input Files

AS2 stores Anu Chopped CSV source files at the project level:

**Actual location**: `./Inputs/ST_Chopped/`

Organized by chapter:
- `ch05/` — Chapter 5 tables (TableE2_RevenueAccounts.csv, Table5_7_KeyRatios.csv, etc.)
- `ch06/` — Chapter 6 tables (Table6_1_TaxAccounts.csv, Table6_2_BenefitAccounts.csv, etc.)
- `ch09/` — Chapter 9 tables (Table9_1_SummaryIndicators.csv)

**Path constant**: `lib/paths.py::ST_CHOPPED`

See `Inputs/ANU_CHOPPED_CATALOG.json` for the full file inventory.
