# External Paper Chapters — Replication Index

## Overview

Chapters 10-17 replicate the quantitative work from 8 academic papers that extend, critique, or apply the Shaikh & Tonak (1994) framework. Each paper is treated as its own "chapter" with full Anu Pipeline processing.

## Series ID Convention

`N` prefix = Non-book (external paper). First two digits = chapter. Last two = series within chapter.

Example: `N1301` = Chapter 13 (Moos 2017), Series 01 (NSW/GDP).
