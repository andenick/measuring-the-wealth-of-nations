# N1001 — Extension Provenance Record

## Agent Understanding

N1001 uses synthetic data estimated from HDARP benchmark values extracted from Tonak's 1984 dissertation. This is NOT original annual data — it is a trend estimate based on reported summary statistics.

## Original Methodology

Tonak computed labor's share of national income (W_p / PI) using BLS and BEA data for 1952-1980. The dissertation reports a declining trend from ~0.73 to ~0.71.

## Current Methodology

Synthetic series generated with linear declining trend, bounded noise, and clipping to ensure values remain within reported range [0.68, 0.76].

## Faithfulness Score

**30%** — LOW. Only the trend direction and approximate range are preserved. Annual values are estimated, not measured.
