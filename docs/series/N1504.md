# N1504: Unproductive Burden Ratio Lu/Lp (Mohun 2013)

**External Study** | study_06_mohun_2013
**Period**: 1964–2010

## From the Book

> Burden ratio = Lu / Lp, the ratio of total unproductive full-time equivalent employment to productive full-time equivalent employment. This is the classic 'unproductive burden' measure: for each productive worker, how many unproductive workers must be supported out of surplus value? A rising ratio represents an increasing drain on surplus value available for accumulation. Mohun (2013) subjects this measure to critical scrutiny by decomposing Lu into working class unproductive (Lu_wc) and supervisory (Lu_sup) components.
