# T703: Value-Price Deviations

**Chapter 7** | Book Table 7.3 | percent
**Period**: 1947–1977

## From the Book

> T703 implements a cross-sectional log-log OLS regression of total labor values against total prices of production across productive sectors, run separately for each IO benchmark year (1947, 1958, 1963, 1967, 1972, 1977). The regression formula is: log(total_labor_values_j) = α + β · log(total_prices_of_production_j) + ε_j, where j indexes productive sectors. R² from this regression measures how well labor values predict market prices, providing an empirical test of the labor theory of value. The book (Shaikh & Tonak 1994, Ch. 7, Table 7.3) claims R² > 0.95 across benchmark years, interpreted as strong confirmation that labor values are the dominant determinant of relative prices of production.
